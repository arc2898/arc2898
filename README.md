### What I'm Working On Right Now

**ZigOS** — Writing an OS from scratch. Zig for the kernel, C++ for the GUI. Currently wrestling with driver framework and memory management. Slow progress, but real progress.

**FepTera** — Started as a hackathon team name (Fe + Peta = new era). Now it's the umbrella for the apps I actually want on my phone: Files, Video, Music, Gallery. No ads, no tracking, just tools that work.

**OS-Vault v2** — Cloud storage I built because I didn't trust the alternatives. v1 runs on Neocities. v2 adds E2E encryption and P2P sync. The hard part isn't the code — it's making sync reliable across flaky mobile networks.

**Linux AI Assistant** — Local-first AI that actually integrates with the system. CLI and GUI. Not a wrapper around an API — runs models locally, has system context, can actually do things.

**Terminal Ecosystem** — arc-terminal, termimg, termsnapshot, linux-brand-modifier. Small tools that make the terminal a better place to live. Because that's where I spend 80% of my time.
